#### **Option 1: Quick Start (Recommended)**
```bash
# Terminal 1 - Start Backend
python start-simple-backend.py

# Terminal 2 - Start Frontend  
cd sri-lanka-ai-planner
npm start
```

#### **Option 2: Individual Start**
```bash
# Backend only
python start-simple-backend.py

# Frontend only
cd sri-lanka-ai-planner
npm start
```
