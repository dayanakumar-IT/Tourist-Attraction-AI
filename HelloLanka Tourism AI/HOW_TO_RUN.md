# 🚀 **How to Run Your Enhanced HelloLanka Tourism AI**

## **✅ SIMPLE METHOD (Recommended)**

### **Option 1: Start Everything at Once**
```bash
# Double-click this file:
START_BOTH.bat
```

### **Option 2: Start Separately**
```bash
# Terminal 1 - Backend:
START_BACKEND.bat

# Terminal 2 - Frontend:
START_FRONTEND.bat
```

## **🎯 What You Get**

### **Enhanced Features:**
- ✅ **High-Quality Images**: Real photos from Unsplash for each place
- ✅ **Smart Timing**: Activity-specific best visit times
- ✅ **Weather Intelligence**: Weather-aware recommendations
- ✅ **Cost Analysis**: Accurate transport costs in LKR
- ✅ **Interactive UI**: Beautiful, expandable day cards
- ✅ **Practical Tips**: Safety advice and local recommendations

### **Access Your App:**
- **Frontend**: http://localhost:3000
